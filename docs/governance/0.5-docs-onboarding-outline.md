## 3. Agent vs human path distinction

Two **first-class** entry paths. Do not collapse them into one doc.

### Human path — S-ONB-HUMAN

| Field | Value |
|-------|--------|
| **Primary doc** | `docs/ONBOARDING.md` |
| **HTML** | `reports/onboarding.html` |
| **Audience** | New human operator (AIE staff, judge dry-run, clean-room reader) |
| **Success** | Zero → env names configured → migrate → seed → deploy notes → first login → demo path (CFP→…→dashboard) under documented time, no tribal knowledge |
| **Owning sections** | 9.2 (prose) · 9.6 (dry-run proof) |
| **Must include (Phase 9)** | Prerequisites; Cloudflare steps (**env names only**); wrangler login pointer; D1/R2 create; migrate; seed; env template (names); first admin invite; demo walk; `pnpm test:e2e` verify; optional Airtable; **timed checklist** |

### Agent path — S-ONB-AGENT

| Field | Value |
|-------|--------|
| **Primary doc** | `docs/AGENT_SETUP.md` |
| **Companion** | `docs/CLI.md` + OpenAPI (`/openapi.json`) + CLI `--help` |
| **HTML** | `reports/agent-setup.html` |
| **Audience** | Coding agent / automated operator with secrets injected out-of-band |
| **Success** | Mint/use scoped API key; complete readiness report + design publish **without human UI** (except secret inject) |
| **Owning sections** | 9.3 (prose + CLI runbook) · 9.6 (agent dry-run proof) · 7.2 (CLI implementation) |
| **Must include (Phase 9)** | Install CLI; bootstrap scoped key; readiness JSON; design publish; upload path; **deny-scope proof**; OpenAPI location; copy-paste agent prompt block |

### Shared / portal — S-DOCS

| Field | Value |
|-------|--------|
| **Tree coherence** | README → architecture → ops → CLI → E2E → security (no orphan critical procedures) |
| **Portal** | **`reports/index.html`** links all HTML reports |
| **Owning sections** | 9.1 IA · 9.4 deep docs · 9.5 HTML generation · 9.6 bundle |

**Secret rule (both paths):** document **variable names only** (`CLOUDFLARE_*`, `AIRTABLE_*`, `RESEND_*`, etc.). Never commit or log secret **values**, API keys, or magic-link tokens in full (E10).
