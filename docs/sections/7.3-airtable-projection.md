## Schema (SCHEMA.md)

### projection_records
`id, system (airtable), entity_type, internal_id, external_id, source_version, updated_at`  
UNIQUE(system, entity_type, internal_id) — upsert identity is **internal_id** (I16).

`processed_at` remains null until consumer drain (or while paused).

## Authz / security

- Status: **admin** role on target event (session)
- Bearer scope `airtable:read`
- Unauthenticated → **401**
- Wrong role → **403** (or **404** cross-event isolation)
- Response validated with Zod; errors use E4 envelope
- **No** Airtable HTTP on request path (E7)
- Env **names** only in repo (E10): `AIRTABLE_API_KEY`, `AIRTABLE_BASE_ID`
- Consequential projection drains emit `audit_events` with `correlationId` (E3)

## Pause survival (S-AIRTABLE)

| Condition | Behavior |
|-----------|----------|
| `AIRTABLE_API_KEY` / `AIRTABLE_BASE_ID` unset | Drain **pauses** (no crash); outbox stays pending |
| Domain mutation (Event.Create/Update) | **200**; inserts `airtable.project` outbox only |
| HTTP 429 from Airtable | Row stays unprocessed with `last_error=rate_limited_429` (no drop) |
| Resume with credentials / sandbox | Drain upserts by `internal_id`; marks processed once |
