# Section 8.1 — Inventory completeness audit

> **Status:** implemented · **Standards:** E1–E12 (`speakerops-engineering-standards.md`) · **Depends:** 2.5, 3.6, 4.4, 5.4, 6.4, 7.4  
> **Souls:** **S-E2E-INV** (machine-check REQUIRED ↔ `@inv` + admin primary control map)

## Goal

Machine-check every REQUIRED inventory ID has a Playwright `@inv:ID` test (or documented non-UI proof), and every **primary admin control** is mapped to inventory via `data-inv`, `controlMap`, or a documented chrome allowlist entry. Hard dependency for Phase 8 full run (8.2) and constitution soul **S-E2E-INV**.

| `scripts/ui-crawl-allowlist.json` | Documented pure-chrome exemptions + `testid → inv` controlMap |

## Discovery crawl (admin primary actions)

**Rule (0.3 law §6):** fail if an admin primary control is unmatched to inventory; allowlist pure chrome only.

| Concept | Definition |
|---------|------------|
| Primary control | `<button>`, `input[type=submit|button]`, or element with `role="button"` in admin surfaces |
| Mapped | `data-inv="A01"` **or** `controlMap` entry (exact or `*` template pattern) to a REQUIRED inventory ID |
| Chrome | Non-action layout/decorative controls listed under `chrome[]` with **non-empty reason** |
| Scope | Static crawl of `apps/web/src/pages` (excludes portal / public CFP / login), `layout/`, `components/` |
| Report missing | Lint stderr lists unmapped testids and files; tag gate lists missing `@inv` IDs |

**Do not** use bare wildcards as the sole acceptance criterion for journeys — controlMap patterns are machine-checked against discovered controls and inventory IDs.

## Security (E10)

- No secrets, API keys, or magic-link tokens in lint, allowlist, tests, or docs
- Env **names** only: `E2E_INVENTORY_GATE`, `E2E_INVENTORY_SKIP_CRAWL`, `E2E_PLAYWRIGHT_RUN_REPORT`, `CI`
- Crawl never executes UI actions or calls product APIs

- Inventory lint + crawl emit structured stdout/stderr lines (`[test:e2e:inventory]`, `inventory-crawl:`)
- Missing tags and unmapped primaries are listed explicitly (no silent pass)
