# Section 1.2 — Worker API health

> **Status:** implemented · **Standards:** E1–E12 (`speakerops-engineering-standards.md`) · **Depends:** 1.1  
> **Soul:** S-CF (health) foundation — live dogfood evidence owned by 8.6

## Goal

Hono app on Cloudflare Workers with `GET /health` returning `{ ok: true, version }` for local and CF smoke.

## Delivered

| Item | Location |
|------|----------|
| Hono composition root | `apps/api/src/index.ts` |
| GET /health | COMMANDS.md HTTP map only |
| E4 error middleware | `apps/api/src/middleware/errors.ts` (404 + 500, no stack leak) |
| correlationId | `x-correlation-id` middleware (E3) |
| Health DTO (Zod) | `packages/shared/src/health.ts` |
| wrangler bindings | root `wrangler.toml` — D1 `DB`, R2 `FILES`, queue `JOBS_QUEUE` (names only) |
| CORS policy note | same-origin by default (no open CORS headers) — see composition root |

## Interfaces

| Method | Path | Success | Failure |
|--------|------|---------|---------|
| GET | `/health` | 200 `{ "ok": true, "version": string }` | 500 E4 envelope if handler throws |
| * | unknown | — | 404 `{ "error", "code": "NOT_FOUND", "details?" }` |

## Out of scope (later sections)

- Auth routes → **2.x**
- Domain routes from COMMANDS.md → feature phases
- Real D1 schema / migrations → **1.3**
- Live CF dogfood deploy + public URL evidence → **8.6** (S-CF claim)

## Security (E10)

- No secrets in `wrangler.toml` — only binding **names**, public `[vars]`, and resource placeholders
- Secrets: `.dev.vars` (gitignored) or `wrangler secret put`
- Env **names** only in docs (`docs/SECRETS.md`)
- Error bodies never include stacks or secret material

## Observability (E3)

- `correlationId` on every request (`x-correlation-id`)
- **audit_events:** N/A — no consequential writes in 1.2 (health is read-only). Write paths must emit audit rows when domain commands land.

## CORS (same-origin)

Dogfood SPA and Worker share origin (or local Vite proxy). This section does **not** set `Access-Control-Allow-Origin: *`. Cross-origin policy is revisited only if a documented public browser origin requires it.
