## Report shape (offline)

- Self-contained HTML (Lumen tokens inlined — E6; no external CSS/CDN)
- **REQUIRED** inventory IDs with **PASS / FAIL** status (and DEFER/other when applicable)
- Inv ID → status: anchor links (`#A01`) + status pills; TOC of REQUIRED IDs
- Status resolution: Playwright `@inv:ID` run outcomes when present; REQUIRED non-DEFER rows without a passed/failed Playwright result are **FAIL** (inventory Status alone cannot green-wash PASS)
- Footer: **generated timestamp** (`data-generated-at`, `<time datetime>`) + **Git SHA**
