# Section 1.5 — Playwright inventory harness

> **Status:** implemented · **Standards:** E1–E12 (`speakerops-engineering-standards.md`) · **Depends:** 1.4, 0.3  
> **Souls:** **S-E2E-INV** (inventory lint + `@inv` map); **S-E2E-RUN** full green is Phase 8

## Goal

Playwright config + inventory linter that fails if any REQUIRED inventory ID lacks `@inv:ID` in tests. Hard dependency for later UI phases and constitution soul S-E2E-INV.

## Delivered

| Item | Location |
|------|----------|
| Playwright config | `playwright.config.ts` |

## Interfaces

| Interface | Behaviour |
|-----------|-----------|
| `pnpm test:e2e:inventory` | Non-interactive; exit **1** when tag targets lack `@inv:ID`; exit **0** when OK |
| `tsx scripts/inventory-lint.ts` | Same entry as above |
| `--allow-missing-until=8.2` | Intermediate default: OPEN rows may lack tags until Phase 8.2 |
| `--phase8` / `E2E_INVENTORY_GATE=phase8` | Allow-missing **OFF**; status PASS + tags + run report |
| `pnpm test:e2e` | Runs Playwright with `playwright.config.ts` |
| `@inv:A01` convention | Documented in `docs/E2E.md` + harness example |
