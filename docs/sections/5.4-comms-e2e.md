## Keystone multi-step path (I12)

1. **Admin login:** magic-link → HttpOnly `speakerops_session`
2. **Create event + seed accepted speakers** (segment audience)
3. **Authz negatives:** unauthenticated send/template → 401
4. **J01:** create template with merge fields via admin SPA
5. **J02:** segment builder shows audience count ≥ 1
6. **J08:** send button disabled until preview; API send without previewId → 400
7. **J03:** preview recipients + rendered bodies; send enabled
8. **J09:** audience edit invalidates preview; send re-disabled
9. **J04:** send once; second send same idempotency key → same job
10. **J05:** delivery log shows job
11. **J06 / J10:** ICS attach SEQUENCE 0 → reschedule SEQUENCE 1 same UID
12. **J07:** evaluator send → 403/404; admin UI access-denied
