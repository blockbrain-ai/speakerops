# Section 1.3 — D1 Drizzle baseline

> **Status:** implemented · **Standards:** E1–E12 (`speakerops-engineering-standards.md`) · **Depends:** 1.2  
> **Soul:** — (supports programme) — schema foundation for all domain sections

## Goal

Drizzle schema + first migration for `organizations`, `events`, `audit_events`, `outbox_events`, `idempotency_keys`, with `pnpm db:generate` / `pnpm db:migrate` and eventId-scoped repository helpers.

## Delivered

| Item | Location |
|------|----------|
| Drizzle schema (E1 path) | `packages/db/schema.ts` |
| Baseline SQL migration | `packages/db/migrations/0001_baseline.sql` |
| Package composition root | `packages/db/src/index.ts` (+ `packages/db/index.ts` re-export) |
| Migrate runner (local SQLite) | `packages/db/src/migrate.ts` · `scripts/db-migrate.mjs` |
| Generate gate | `scripts/db-generate.mjs` |
| Repository helpers (eventId) | `packages/db/src/repository.ts` |
| D1 client factory | `packages/db/src/client.ts` (`createDb`) |
| wrangler migrations_dir | root `wrangler.toml` → `packages/db/migrations` |

## Schema (SCHEMA.md columns only)

### organizations
`id, name, created_at, updated_at`

### events
`id, org_id, name, slug, timezone, starts_at, ends_at, settings_json, created_at, updated_at, **version**`

### audit_events
`id, event_id NULL, actor_type, actor_id, action, entity_type, entity_id, before_json, after_json, correlation_id, created_at`

### outbox_events
`id, topic, payload_json, created_at, processed_at, attempts, last_error`

### idempotency_keys
`id, key, request_hash, response_json, created_at`

## Interfaces

| Interface | Behaviour |
|-----------|-----------|
| `Migration applies clean on empty D1` | `pnpm db:migrate` applies `0001_baseline.sql` on empty SQLite/D1 |
| schema exports | `organizations`, `events`, `auditEvents`, `outboxEvents`, `idempotencyKeys` |
| Second migrate | no-op (tracked in `schema_migrations`) |
| `requireEventId` / `eventScoped` | repository pattern stub (E2) |
| `buildAuditEventRow` | requires `correlationId` (E3) for domain writes |

## Commands

```bash
pnpm db:generate   # verify schema + 0001 inventory (non-interactive)
pnpm db:migrate    # apply pending migrations to SPEAKEROPS_DB_PATH or .data/speakerops.local.sqlite
pnpm typecheck
pnpm test:ci       # includes packages/db migrate tests + governance 1.3
```

Local DB path env **name** only: `SPEAKEROPS_DB_PATH` (see `docs/SECRETS.md` for deploy secrets; migrate itself needs no tokens).
