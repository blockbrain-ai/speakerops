# Section 1.1 — Monorepo and CI gates

> **Status:** implemented · **Standards:** E1–E12 (`speakerops-engineering-standards.md`) · **Depends:** 0.1, 0.5

## Goal

pnpm monorepo with `apps/web`, `apps/api`, `packages/{shared,db,cli}`, and non-interactive `typecheck` / `test:ci` so Section Runner gates never hang.

## Delivered

| Item | Location |
|------|----------|
| Workspace | `pnpm-workspace.yaml` |
| Root gates | `package.json` → `typecheck`, `test:ci`, `test:e2e`, `test:e2e:inventory`, `db:*`, `docs:reports` |
| Packages | `apps/api`, `apps/web`, `packages/shared`, `packages/db`, `packages/cli` |
| TS project references | root `tsconfig.json` + per-package `tsconfig.json` |
| Vitest (non-watch) | `vitest.config.ts` (`watch: false`) |

| Shared E4 + Zod | `packages/shared/src/errors.ts` |

| Composition roots | API / web / CLI as locked in CLAUDE.md |

## Out of scope (later sections)

- `GET /health` and wrangler bindings → **1.2**

## Gates proof

```bash
pnpm typecheck   # tsc -b — exit 0
pnpm test:ci     # node --test tests/ && vitest run — exit 0, ≥1 unit test
```

No `--watch` on gate scripts; Vitest `watch: false`.
