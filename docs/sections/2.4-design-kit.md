## Schema (SCHEMA.md)

### design_token_drafts
`event_id PK, tokens_json, version, created_at, updated_at`

### design_token_published
`event_id PK, tokens_json, version, published_at, published_by`

### Tokens JSON
`{ brand, brandSoft, radius, wordmark, logoFileId, brandFg? }`

### file_assets (logo presign)
`id, event_id, r2_key, filename, mime, size, purpose, …` — purpose=`logo`, mime allowlist `image/png` only.

Event-scoped queries always take `eventId` at the store layer (E2).

## Interfaces

```http
GET    /api/events/:eventId/design
PUT    /api/events/:eventId/design
POST   /api/events/:eventId/design/publish
GET    /api/public/design/:slug
GET    /api/public/design/:slug/css
POST   /api/files/presign
```

Authz: admin role via `requireRole` (session) for write paths. Unauthenticated → 401;
wrong role → 403; no membership on target event → 404. Validation → 400 E4 envelope.
Publish contrast failure → 400 `CONTRAST_FAILED` (or success with derived `brandFg`).
Consequential writes emit `audit_events` with `correlationId` (E3).

## Contrast gate (S-THEME / MF)

- Derive `brandFg` (white or near-black) for primary-button text on brand background.
- Block publish when ratio &lt; 3:1 (UI AA). Near-white `#fffffe` derives dark safe fg and publishes.
- Public CFP applies **published** CSS variables only; admin chrome never rethemes.
