1. **Admin login:** magic-link → HttpOnly `speakerops_session`
2. **Authz negatives:** unauthenticated keys / airtable status → **401**
3. **K01:** create key with subset of scopes; secret shown once
4. **K03:** dismiss secret; only prefix remains; copy-prefix control
5. **K02:** revoke key; revoked Bearer → **401**
6. **K04:** speaker role cannot open keys UI; API → **403**
7. **CLI07 deny:** mint reports-only key → `schedule place` via HTTP **403** + spawn `speakerops` → exit **2** / FORBIDDEN
8. **Airtable pause:** Event.Update **200** while credentials unset; status `paused=true`, `pendingCount≥1`
9. **O06:** admin Settings → Airtable status UI shows lag + paused
