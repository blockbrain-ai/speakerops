## Schema (SCHEMA.md)

### people
`id, org_id, email, name, created_at, updated_at` — UNIQUE(org_id, email)

### submissions
`id, event_id, form_version_id, title, category, status, submitted_at, version`  
Public create writes `status=submitted` and **pins** `form_version_id` to the latest published version.

### submission_answers
`id, submission_id, field_key, value_json` — only **visible** fields stored (hidden conditionals stripped)

### submission_speakers
`submission_id, person_id, is_primary, sort_order`

## Interfaces

```http
GET    /api/public/cfp/:slug                 → Form.GetPublic (+ windowState, speaker bounds, file meta)
POST   /api/public/cfp/:slug/submissions     → Submission.Create
POST   /api/public/cfp/:slug/files           → public supporting file (mime/size allowlist)
GET    /openapi.json                         → includes Submission.Create
```

SPA: `GET /cfp/:slug` → `PublicCfpPage` (brand tokens from Design.GetPublic + form from Form.GetPublic).

## Authz / security

- Public create (no session); rate-limited per client IP (`X-RateLimit-*`, `429 RATE_LIMITED`)
- Turnstile server verify (`TURNSTILE_SECRET_KEY` + `TURNSTILE_SITE_KEY` env **names** only; production Worker requires both at construction and rejects development/Cloudflare test secrets and the always-pass test site key so the SPA never falls open to local/always-pass modes; local/e2e when secret unset only explicit dev pass token `XXXX.DUMMY.TOKEN` is accepted — fail-closed)
- Closed / not-yet-open window → 400; wrong `form_version_id` pin → 400
- File mime allowlist: `application/pdf`, `image/png`, `image/jpeg` (max 5 MiB); SVG/HTML/JS rejected
- XSS-safe UI: welcome, thank-you, and answer echo as **text nodes** only (no `dangerouslySetInnerHTML`)
- Consequential writes emit `audit_events` with `correlationId` (E3)
