## Interfaces (UI → Form.* only)

```http
POST   /api/events/:eventId/forms   → Form.Create
PUT    /api/forms/:formId/draft     → Form.UpdateDraftFields
POST   /api/forms/:formId/publish   → Form.Publish
GET    /api/public/cfp/:slug        → Form.GetPublic (verify after publish)
```

No invented admin list/get endpoints. Working draft is held client-side after Create; Save draft / Publish push full field+rule+meta replace.

## Behaviour notes

- **Empty state:** no fields → empty list message; **Publish disabled** until ≥1 valid field.
- **Circular conditionals:** client blocks save/publish; API also returns 400 (3.1).
- **Preview:** always side-by-side when workspace open (cannot publish “without preview” surface).
- **Publish:** saves draft first, then `Form.Publish` freezes immutable `form_versions` row; further draft edits + publish increment `version_num`.
- **Public link:** `/cfp/:eventSlug` via active event slug (D10 clipboard).
- **Field types:** closed set from `FormFieldTypeSchema` (3.1). “File” palette adds `url` type; “Speaker name” adds `text` with `speaker_name` key (multi-speaker submit is 3.3).

## Performance notes

- Admin palette add + preview re-render is local state only (p95 &lt; 200ms after warm for seed ≤150 fields on typical laptop).
- Save/publish is one replace draft + optional publish HTTP call; no N+1 field POSTs.

## Out of scope

- Public multi-speaker submit + Turnstile (3.3)
- File binary upload on CFP (3.3 / 4.x)
- Dual-write Airtable; freeform CSS; Next/RSC; OR-Tools
