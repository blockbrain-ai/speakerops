## Keystone multi-step path (I12)

1. **Unauthed guard (B04):** `GET /api/events` → 401; `/admin` → `/login`
2. **Admin login (B01):** magic-link request → dev outbox token → exchange → HttpOnly `speakerops_session` → admin shell
3. **Create event (C01):** `POST /api/events` with timezone
4. **Design Kit (C03/C05/C06/C10):** set brand + wordmark; no freeform CSS; draft isolated; publish
5. **Public brand (C05 / S-THEME):** `/cfp/:slug` shows published brand hex + wordmark
6. **Role guards (B05/B06):** speaker → access-denied + API 403; evaluator schedule place → 403
