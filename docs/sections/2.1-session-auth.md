## HTTP (COMMANDS.md)

| Method | Path | Command | Success |
|--------|------|---------|---------|
| POST | `/api/auth/magic-link` | `Auth.RequestMagicLink` | 200 `{ sent: true }` |
| POST | `/api/auth/exchange` | `Auth.ExchangeMagicLink` | 200 + `Set-Cookie` |
| POST | `/api/auth/logout` | `Auth.Logout` | 204 + clear cookie |

### Cookie flags

`speakerops_session=<token>; Path=/; HttpOnly; Secure; SameSite=Lax; Max-Age=…`

### Security

- Tokens stored **only** as SHA-256 hex (`token_hash`) — never plaintext in DB
- Single-use magic links (`used_at`); replay → 401 `UNAUTHORIZED`
- Unknown email still returns `{ sent: true }` (no enumeration)
- Never log magic-link or session tokens (E10)
- Consequential writes → `audit_events` with `correlationId` (E3)
- Zod validation + E4 envelopes on all auth handlers (E4)

## Schema (SCHEMA.md)

### users
`id, email, name, created_at, updated_at` (+ unique index on email)

### auth_sessions
`id, user_id, token_hash, expires_at, created_at`

### magic_links
`id, user_id, event_id NULL, purpose, token_hash, expires_at, used_at, created_at`

## Dev transport

Local e2e (`scripts/e2e-api-server.mjs`) uses `createAppWithAuth({ enableDevOutbox: true })`.

- Captures plaintext tokens **in process memory only** (never DB)
- `GET /api/auth/dev/outbox?email=` returns last token for Playwright
- **Not** registered on production default export (`enableDevOutbox: false`)

## Out of scope
