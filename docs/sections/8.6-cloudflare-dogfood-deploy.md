## Interfaces

### `scripts/deploy-dogfood.sh`

```bash
# Missing creds → exit 1 + message (gate-tested)
env -u CLOUDFLARE_API_TOKEN -u CLOUDFLARE_ACCOUNT_ID bash scripts/deploy-dogfood.sh

# Operator deploy + health smoke + evidence rewrite
scripts/with-secrets.sh bash scripts/deploy-dogfood.sh

# Dry-run (creds present, no network deploy)
DEPLOY_DRY_RUN=1 scripts/with-secrets.sh bash scripts/deploy-dogfood.sh

# Health-only re-smoke
SMOKE_BASE_URL=https://<worker>.workers.dev DOGFOOD_SKIP_DEPLOY=1 \
  scripts/with-secrets.sh bash scripts/deploy-dogfood.sh
```

| Exit | Meaning |
|------|---------|
| 0 | Creds present and smoke path completed (or dry-run) |
| 1 | Missing `CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_ACCOUNT_ID`, or deploy/smoke failed |

### Optional `SMOKE_BASE_URL` Playwright

When set, `playwright/e2e/cf_dogfood_smoke.spec.ts` asserts remote `GET /health` → 200.
When unset, the test **skips** (no `@inv` ownership).
