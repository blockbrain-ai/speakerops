## Security (E10)

- No secrets in web app or Vite config
- Env **names** only in docs
- Vite proxy targets local Worker by host/port only (no tokens)

## Observability

- correlationId / audit_events: server-side (API). SPA does not invent client audit buses.

## Theme invariants (E6 / S-THEME)

- Light default (`color-scheme: light`); **no dark-default** theme
- `--lumen-brand`, `--lumen-focus-ring`, status soft pairs present
- Admin chrome ignores event brand retheme (blast radius: public CFP + speaker portal only)
- Layout CSS uses `var(--lumen-*)` only — no freeform palette
