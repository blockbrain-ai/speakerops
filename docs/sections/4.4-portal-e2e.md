## Keystone multi-step path (I12)

1. **Admin login:** magic-link → HttpOnly `speakerops_session`
2. **Create event:** `POST /api/events`
3. **Task templates (O05):** `on_accept` templates (future + overdue) + admin templates UI visible
4. **Seed accept:** form publish → public CFP submit → `Decision.Record` accept → session + speaker_tasks
5. **Authz negatives:** unauthenticated portal home → 401; speaker TaskTemplate.Create → 403
6. **Speaker portal (G01–G08):** next task home → overdue visual → own session → bio XSS text-only → headshot (bad type rejected + JPEG) → slides PDF → task complete → mobile bio + completed state
