## Behaviours

### Next task home (G01)
- Renders `nextTask` from incomplete tasks ordered by dueAt
- Complete control on next-task card

### Profile bio (G02)
- Textarea → `Participation.UpdateProfile` with `expectedVersion`
- `sanitizeBioText` strips tags/handlers; UI never uses `dangerouslySetInnerHTML`
- Preview and save path are text nodes only (assert bio XSS text content not script)

### Files (G03/G04)
- Headshot: JPEG/PNG presign → upload → complete → local object-URL preview; binds `headshotFileId`
- Slides: PDF only same path
- Client mime gate rejects executables before presign

### Tasks (G05/G06)
- Optimistic complete + revert on network/4xx/5xx (toast)
- Overdue visual: `pending` with `dueAt <= now` or status `overdue` → danger badge + `.portal-task--overdue`

### Sessions (G07)
- Own sessions from Portal.GetHome only; privacy note; no cross-speaker private data

### Mobile (G08)
- Viewport 375×667; bio save + task complete; CSS `@media (max-width: 480px)` full-width controls
