## Keystone multi-step path (I12)

1. **Admin login:** magic-link → HttpOnly `speakerops_session`
2. **Create event** with timezone + schedule window; rooms/tracks; overdue task template
3. **Seed sessions** (main, conflict pair, room peer, move, stale, undo) via Session.CreateDirect
4. **Authz negatives:** unauthenticated schedule place / readiness → 401
5. **S-SCHED (I01–I16):**
   - I12 timezone label
   - I11 unscheduled tray
   - I06 drag place
   - I01 list; I02–I05 five views consistent
   - I07 speaker conflict blocked; I08 room overlap blocked
   - I09 keyboard place; I10 undo
   - I13 move; I14 unschedule; I15 stale recovery; I16 reload
6. **S-READY (H01–H05):**
   - H01 stats + outstanding
   - H02 filter overdue
   - H03 drill to speaker detail
   - H04 live poll ≤5s after portal Task.Complete
   - H05 empty state on event with no speakers
7. **N01–N04:** speakers list, search filter, detail tasks/files, cross-event leak denied
8. **L05:** 150-row seed list paginates (page size 25)
