## Schema (SCHEMA.md)

### schedule_placements
`id, event_id, session_id, room_id, starts_at, ends_at, version, created_at, updated_at`  
UNIQUE(session_id) — one placement per program session (use Move to reschedule)

### room_block_reservations
`id, event_id, room_id, placement_id, starts_at, ends_at, created_at`  
UNIQUE(event_id, room_id, starts_at, ends_at) + domain overlap checks

### speaker_block_reservations
`id, event_id, participation_id, placement_id, starts_at, ends_at, created_at`  
UNIQUE(event_id, participation_id, starts_at, ends_at) + domain overlap checks

### Conflict response (409)

```json
{
  "error": "Schedule conflict",
  "code": "CONFLICT",
  "conflicts": [
    { "type": "speaker", "message": "Speaker is already booked from … to …" },
    { "type": "room", "message": "Room is already booked from … to …" }
  ]
}
```

Plain type codes: `room` | `speaker` | `session`.

### Version response (409)

```json
{
  "error": "Version conflict",
  "code": "VERSION",
  "details": { "expectedVersion": 1, "actual": 2 }
}
```

## Authz

- Role: **admin** only (evaluator/speaker → 403; no membership → 404)
- Scopes (later API keys): `schedule:read` / `schedule:write` (SCOPES.md)
- Never trust CLI/UI alone

## Failure modes addressed

| Mode | Mitigation |
|------|------------|
| Silent double book | Overlap detect + unique reservation indexes → 409 CONFLICT |
| Partial multi-row write | Bundle insert with rollback on failure (memory atomic; D1 cleanup) |
| Wrong event placement | eventId on placement; cross-event path → 404 |
| Missing version check | Move/Unschedule require expectedVersion → 409 VERSION |

> **Post-11.9 depth (Wave 2):** `Schedule.Place` / `Schedule.Move` enforce the event's **agenda day window** (settings_json `agendaDayStart`/`agendaDayEnd`, wall clock in the event timezone): out-of-window or cross-midnight placements return **409 CONFLICT** with `conflicts[]` type **`hours`** and a human message naming the window. Unconfigured events keep their legacy envelope (defaults 09:00–17:00 widened by the event's own start/end wall times). The Studio grid renders exactly the enforced window at the configured `slotIntervalMin`. Inventory **I17**.
