## Schema (SCHEMA.md)

### eval_rounds
`id, event_id, name, status (open|closed), closes_at, created_at, updated_at`

### eval_criteria
`id, round_id, name, max_score, weight, sort_order`

### eval_assignments
`id, round_id, submission_id, evaluator_user_id, status (pending|scored), overall_comment, created_at, updated_at`  
UNIQUE(round_id, submission_id, evaluator_user_id)

### scores
`id, assignment_id, criterion_id, value, comment` UNIQUE(assignment_id, criterion_id)

## Authz / security

- Rubric / rollup / assign: **admin** role on event (404 if no membership)
- Queue: session + evaluator or admin membership (403 otherwise)
- Score: session + evaluator/admin membership; **only own assignment** (403 if not assignee)
- Score value `> max_score` or `< 0` → **400** `VALIDATION_ERROR`
- Unauthenticated → **401**
- Consequential writes emit `audit_events` with `correlationId` (E3)
- No AI scoring; no Decision.Record on evaluator surface (F03)

## Aggregate score

Weighted mean: `sum(value * weight) / sum(weight)` per assignment.  
Admin rollup: mean of assignment aggregates for the submission.
