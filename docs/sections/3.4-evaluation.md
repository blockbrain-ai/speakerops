## Authz / security

- Rubric / rollup / assign: **admin** role on event (404 if no membership)
- Queue: session + evaluator or admin membership (403 otherwise)
- Score: session + evaluator/admin membership; **only own assignment** (403 if not assignee)
- Score value `> max_score` or `< 0` → **400** `VALIDATION_ERROR`
- Unauthenticated → **401**
- Consequential writes emit `audit_events` with `correlationId` (E3)
- No AI scoring; no Decision.Record on evaluator surface (F03)

## Aggregate score

Weighted mean: `sum(value * weight) / sum(weight)` per assignment.  
Admin rollup: mean of assignment aggregates for the submission.

> **Post-11.9 depth (Wave 1A):** evaluators can **abstain** from an assignment (`POST /api/me/eval-assignments/:id/abstain`, owner-verified, optional reason; status `abstained`, migration `0025`) — abstentions leave the pending flow, never count toward aggregates, and surface distinctly in the admin rollup + CSV (`abstainedCount`/`abstainReasons`). Rubric settings gained a **review deadline** picker (`closesAt`) and **evaluator instructions** (`instructions_md`, migration `0026`; plain-text render in the queue banner); `Eval.Score` and `Eval.Abstain` return **409 after close** and the queue shows an honest closed state. Admin evaluations adds **insights**: completion bar, Top 10 by aggregate (linked to submission detail), and a divergence list driven by the new `scoreSpread` rollup field. Inventory **F10–F12**.

> **Post-11.9 depth (Wave 1B):** rubric settings gained **“Hide speaker identities from evaluators”** (`eval_rounds.hide_speakers`, migration `0029`). When on, the evaluator proposal DTO **omits `speakers[]` server-side** (never CSS) and the queue shows an honest hidden-roster note; the helper copy states plainly that titles and answers may still reveal identity, and admin surfaces are unchanged. Toggling off restores the roster on the next proposal load. Inventory **F13**.

> **Post-11.9 depth (Wave 2):** admins bulk-assign a whole round from the evaluations page (`Eval.BulkAssign`): a **preview** (`dryRun`) computes a deterministic plan — submissions and evaluators in id order, `all_to_all` or `round_robin` (`reviewersPerSubmission`, `maxPerEvaluator`), `existing=preserve|replace` with scored/abstained reviews **never** removed — and returns a `previewId` hashed over the estate. The **commit** requires that previewId, returns **409 "preview is stale"** on drift, and is single-use/idempotent via `idempotency_keys`. No migration. Inventory **F14**.
