## Interfaces

### Headers on all Worker responses

| Header | Value (summary) |
|--------|-----------------|
| `Content-Security-Policy` | Shared `CONTENT_SECURITY_POLICY` (self + Turnstile + fonts) |
| `X-Content-Type-Options` | `nosniff` |
| `Referrer-Policy` | `strict-origin-when-cross-origin` |
| `X-Frame-Options` | `DENY` |
| `Permissions-Policy` | camera/mic/geo/payment/usb disabled |
| `Cross-Origin-Opener-Policy` | `same-origin` |

### Public CFP (unchanged contracts; hardened proofs)

- Turnstile verify (fail-closed; production keys required)
- Rate limit → `429` + `RATE_LIMITED` + `X-RateLimit-*` / `Retry-After`
- Session cookies: HttpOnly + Secure + SameSite=Lax

No new COMMANDS.md routes. No schema migrations.
