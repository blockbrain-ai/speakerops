## Keystone multi-step path (I12)

1. **Admin login:** magic-link → HttpOnly `speakerops_session`
2. **Create event:** `POST /api/events`
3. **Form publish (S-CFP / D08):** admin UI create form + field → publish version 1
4. **Public submit (S-CFP / A06):** `/cfp/:slug` fill + Turnstile test key → confirmation
5. **Rubric + assign + score (S-EVAL / F02 / O04):** rubric upsert → assign evaluator → score UI save
6. **Accept → tasks (S-EVAL / E04):** admin accept → programme session + default `on_accept` speaker_tasks (≥2)
7. **Authz negatives:** evaluator Decision.Record → 403; unauthenticated → 401; score out-of-range → 400
