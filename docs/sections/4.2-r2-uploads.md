## Schema (SCHEMA.md)

### file_assets
`id, event_id, owner_participation_id, r2_key, filename, mime, size, checksum, purpose, created_at, uploaded, virus_scan_status`

- **Metadata in D1 only** — bytes in R2 (`FILES` binding) under `r2_key`
- `virus_scan_status` stub: always `unscanned` on create (no scanner in 4.2)
- Mime allowlists: logo `image/png`; headshot `image/jpeg|image/png`; slides `application/pdf`
- Blocked: `application/x-msdownload` and other executables/SVG/HTML/JS

## Interfaces

```http
POST   /api/files/presign                 → File.PresignUpload
PUT    /api/files/:fileId/upload?eventId= → File.Upload
POST   /api/files/:fileId/complete        → File.CompleteUpload
GET    /api/public/files/:fileId          → File.GetPublic (logo published only)
```

Authz:
- **logo** presign/upload: admin on event
- **headshot|slides** presign/upload/complete: speaker or admin on event
- Unauthenticated → **401**
- Wrong role → **403**
- Invalid mime/body → **400** VALIDATION_ERROR (E4)
- Private headshot/slides never served by public GET (download requires auth)
