> **Status:** implemented · **Standards:** E1–E12 · **Depends:** 2.3

Versioned forms API: fields, conditionals, category routing, publish immutable version.

## Schema (SCHEMA.md)

### forms
`id, event_id, name, status, created_at` — status `draft` \| `published`

### form_versions
`id, form_id, version_num, welcome_md, thank_you_md, opens_at, closes_at, submission_limit, published_at, snapshot_json`

- Draft working copy: `version_num = 0`, `published_at` NULL
- Publish: inserts immutable row with `version_num++`, freezes `snapshot_json`

### form_fields
`id, form_version_id, field_key, type, label, required, options_json, sort_order, conditions_json`

- `field_key` is stable (snake_case) for `submission_answers` consumers (I16)

### form_rules
`id, form_version_id, when_json, route_to_category` — category routing

Event-scoped queries always take `eventId` via the form shell (E2).

## Interfaces

```http
POST   /api/events/:eventId/forms
PUT    /api/forms/:formId/draft
POST   /api/forms/:formId/publish
GET    /api/public/cfp/:slug
GET    /openapi.json
```

Authz: admin role via `requireRole` (session) for write paths. Unauthenticated → 401;
wrong role → 403; no membership on target event → 404. Validation → 400 E4 envelope
(including invalid condition `field_key`). Consequential writes emit `audit_events` with
`correlationId` (E3).

## Performance notes

- Admin draft replace is O(fields + rules) per form; seed ≤150 fields stays well under p95 &lt; 200ms local after warm (in-memory store path is map replace).
- Public CFP first interaction loads published form only (no draft leak); skeleton allowed on SPA (3.2/3.3).
