## Generator interface

```bash
pnpm docs:reports
# equivalent:
pnpm exec tsx scripts/build-docs-reports.ts
pnpm exec tsx scripts/build-docs-reports.ts --out-dir=path --no-e2e
```

| Flag / env | Role |
|------------|------|
| `--out-dir=path` | Output directory (default `reports/`) |
| `--no-e2e` | Skip refreshing `e2e-coverage.html` via 8.5 builder |
| `DOCS_REPORTS_DIR` | Env **name** for output directory override |

Each page includes:

- Shared **light** Lumen CSS variables (E6; `color-scheme: light`; no dark default)
- Sticky **nav** between report pages
- Footer with **generated-at** ISO timestamp + **git SHA**
- No secret values (E10)

## Security (E10)

- Env **names** only (`DOCS_REPORTS_DIR`)
- Never logs or embeds API keys, magic-link tokens, or Bearer values
- Source markdown is rendered offline; does not invent product endpoints

## Scope guard
